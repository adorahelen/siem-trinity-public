# security-log-monitor 작업 기록 — 2026-03-13

## 1. 대시보드 구조 재배치

기존 보안 대시보드는 성격이 다른 패널이 한 화면에 뒤섞여 있었고, 1분 주기 새로고침과 24시간 Loki range query가 동시에 몰리면서 `too many outstanding requests`가 반복됐다.

이번 변경에서는 패널을 아래 4개 영역으로 재배치했다.

1. `실시간 요약`
2. `조사`
3. `시스템`
4. `네트워크 센서`

상단에는 집계형 timeseries만 남겼다.

- `SSH Invalid user 추이 (24h)`
- `fail2ban Ban/Unban 이벤트 (24h)`
- `KR-BLOCK 차단 이벤트 (24h)`
- `Nginx 상태코드 분포 (24h)`

하단에는 조사성 패널과 상세 로그를 모았다.

## 2. 쿼리 경량화 기준

### 2-1. 집계형 상단 패널

고카디널리티 라벨을 직접 노출하던 쿼리를 `sum(...)` 형태로 단순화했다.

예:

```logql
sum(count_over_time({job="auth"} |= "Invalid user" [5m]))
sum(count_over_time({job="fail2ban"} |= "Ban" [5m]))
sum(count_over_time({job="kern", kern_event="[KR-BLOCK]"} [5m]))
```

### 2-2. 조사 패널

`Top`, `분포`, `랭킹` 성격의 패널은 `instant` query로 전환했다.

대상:

- `Top SSH 공격 IP (24h)`
- `Top 차단 목적지 포트 (KR-BLOCK 24h)`
- `웹 방문 유형 분포 (24h)`
- `Suricata 이벤트 유형 분포`
- `Top 공격 IP (Suricata)`
- `Suricata 탐지 시그니처 Top 10`
- `ModSecurity Top Rule (24h)`

### 2-3. Wazuh 패널 수정

기존 쿼리:

```logql
{job="wazuh"} | json | level >= `7`
```

이 쿼리는 현재 Loki에서 parse error를 냈다.

수정 후:

```logql
{job="wazuh", level=~"([7-9]|1[0-5])"}
sum by (level) (count_over_time({job="wazuh", level=~"([7-9]|1[0-5])"}[5m]))
```

즉 high severity 경보만 따로 본다.

## 4. Loki 설정 조정

대시보드 쿼리 fan-out 완화를 위해 Loki 설정을 수정했다.

파일:

`config/loki-config.yml`

변경 내용:

```yaml
frontend:
  max_outstanding_per_tenant: 8192

query_scheduler:
  max_outstanding_requests_per_tenant: 65536

limits_config:
  split_queries_by_interval: 24h

querier:
  max_concurrent: 8
```

의도:

- query split 수를 줄여 단일 노드 Loki에서 과도한 subquery fan-out 방지
- query frontend / scheduler outstanding queue 한도 완화
- querier 동시 처리 수를 기본값보다 높여 다수 패널 동시 조회 완화

## 5. 검증

### 대시보드 API

- refresh: `5m`
- 신규 패널 확인:
  - `ModSecurity 이벤트 추이 (24h)`
  - `ModSecurity Top Rule (24h)`
  - `Top 차단 목적지 포트 (KR-BLOCK 24h)`
  - `Tailscale 연결 상태`
  - `Wazuh High 알림 레벨별 추이 (24h)`
  - `최근 Wazuh High 알림 목록`

### Loki 직접 질의

성공 확인:

```bash
sum(count_over_time({job="kern", kern_event="[KR-BLOCK]"} [5m]))
sum(count_over_time({job="auth"} |= "Invalid user" [5m]))
topk(20, sum by (src_ip) (count_over_time({job="auth"} |= "Invalid user" [24h])))
sum by (level) (count_over_time({job="wazuh", level=~"([7-9]|1[0-5])"}[5m]))
topk(10, sum by (rule_id) (count_over_time({job="modsec"}[24h])))
```

모두 `success` 응답 확인.

### exporter

`python3 exporter/collector.py` 재실행 시 Loki push 정상 확인:

- `ss_ports`
- `tailscale_status`
- `nginx_*`
