# Mobile 보안 관점 정리

- 작성 일시: 2026-03-13 KST
- 목적: 현재 `security-log-monitor` 프로젝트와 별도로 모바일 보안/관제 논의를 축적하기 위한 기준 문서

---

## 현재 전제

이 문서는 아래 3가지 전제를 기준으로 작성한다.

1. 모바일 애플리케이션을 새로 만든다.
2. 대상 단말은 다음 두 경우를 모두 포함할 수 있다.
   - `USIM`이 없는 공기계
   - `USIM`이 장착된 일반 휴대폰
3. 두 단말 모두 네트워크에 연결되지 않는다면 `에어갭 상태`로 간주한다.

---

## 단말 구분

### 1. 공기계

- `USIM`이 없을 수 있다.
- 셀룰러 네트워크 사용이 제한될 수 있다.
- 단, `Wi-Fi`, `Bluetooth`, `USB`, `NFC` 등 다른 통신 수단은 여전히 존재할 수 있다.

즉, `USIM 없음 = 완전한 오프라인`은 아니다.

### 2. 일반 휴대폰

- `USIM`이 장착되어 있을 수 있다.
- 이동통신망을 통한 데이터 통신 가능성이 있다.
- 추가로 `Wi-Fi`, `Bluetooth`, `USB`, `NFC` 등도 사용할 수 있다.

즉, 일반 휴대폰은 공기계보다 외부 연결 가능성이 더 넓다.

---

## 에어갭 상태에 대한 현재 판단

현재 관점은 다음과 같다.

- 두 단말 모두 어떤 네트워크에도 연결되지 않으면 `에어갭 상태`다.
- 이 경우 원격 공격이나 원격 정보 유출 가능성은 매우 낮아진다.
- 따라서 물리적 접근이 없는 한 공격 또는 유출 가능성은 크게 줄어든다고 본다.

이 판단은 실무적으로도 큰 방향에서는 타당하다.

---

## 에어갭 상태에서의 기본 결론

네트워크 연결이 모두 차단되어 있다면, 모바일 단말은 아래 위험으로부터 상당 부분 자유로워진다.

- 원격 스캔
- 외부 API 악용
- 인터넷 경유 명령 전달
- 서버와의 실시간 데이터 유출
- 일반적인 네트워크 기반 공격

즉, 이 상태에서는 현재 `security-log-monitor` 같은 네트워크/로그 관제 시스템과의 직접 연관성이 매우 약해진다.

왜냐하면:

- 전송되는 로그가 없고
- 서버와 통신도 없고
- 외부 네트워크 이벤트도 없기 때문이다.

---

## 다만 완전 무위험은 아님

에어갭 상태라고 해서 절대 안전한 것은 아니다.

남아 있는 리스크 예시:

- 물리적 탈취
- 잠금 해제 후 수동 조작
- 악성 `USB` 연결
- 디버깅 케이블 연결
- 로컬 저장소 추출
- `Bluetooth`, `NFC`가 켜져 있을 경우 근거리 공격 가능성
- 사전에 이미 악성 앱이나 악성 설정이 들어가 있었던 경우

즉, `에어갭 = 네트워크 기반 위험 감소`로 이해하는 것이 정확하다.
`모든 공격이 불가능`한 것은 아니다.

---

## 현재 프로젝트와의 관계

현재 `security-log-monitor` 프로젝트는 본질적으로 아래를 관제한다.

- 서버 로그
- 웹 로그
- 호스트 보안 이벤트
- 일부 네트워크 이벤트

따라서 모바일 단말이 완전히 오프라인이라면 현재 프로젝트와의 직접 연결점은 거의 없다.

연결점이 생기려면 아래 중 하나가 필요하다.

- 모바일 앱이 로그를 서버로 전송
- 모바일 단말이 Wi-Fi 또는 셀룰러로 네트워크에 연결
- 모바일 분석 결과를 별도 파일/JSON 형태로 서버에 적재
- USB 등으로 추출한 결과를 프로젝트에 수동 반입

즉, `오프라인 모바일 단말`은 현재 프로젝트의 기본 관제 범위 밖에 있다.

---

## 향후 논의 기준

앞으로 모바일 보안 논의는 아래 3개 축으로 나누어 생각한다.

### 1. 오프라인 단말 보안

- 에어갭 상태
- 물리 접근 위협
- 로컬 저장소 보호
- 루팅/포렌식 필요 여부

### 2. 앱 자체 보안

- 앱 무결성
- 루팅 탐지
- 위변조 탐지
- 디버거/후킹 탐지
- 민감 데이터 저장 방식

### 3. 온라인 연결 후 관제

- 앱 로그 전송
- API 호출 모니터링
- 모바일 보안 이벤트 수집
- 서버 측 탐지 및 SIEM 연계

---

## 현재 시점의 요약

- 모바일 애플리케이션은 앞으로 새로 만들 예정이다.
- 대상 단말은 공기계와 일반 휴대폰을 모두 포함할 수 있다.
- 네트워크에 연결되지 않은 상태라면 원격 공격 및 원격 유출 가능성은 크게 낮다.
- 다만 물리 접근, USB, 근거리 무선, 사전 감염 같은 위험은 남아 있다.
- 이런 오프라인 단말은 현재 `security-log-monitor`의 직접적인 관제 대상이 아니다.
