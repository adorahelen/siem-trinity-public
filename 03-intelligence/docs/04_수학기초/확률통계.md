## 왜 AI에 확률통계가 필요한가

```
LLM의 출력은 확률:
  "다음 토큰이 무엇인가?" → 각 토큰의 확률 분포
  "공격" 확률 0.72, "정상" 확률 0.28 → "공격" 선택

손실 함수는 확률 기반:
  Cross-Entropy: 예측 확률 분포와 실제 분포의 차이

Temperature 제어:
  확률 분포를 날카롭게/평평하게 조절
```

---

## 확률 기본 개념

```
확률: 사건이 발생할 가능성 (0 ~ 1)

조건부 확률:
  P(A|B) = B가 주어졌을 때 A의 확률

  LLM에서:
  P("먹었다" | "나는 밥을") = 0.65
  P("먹겠다" | "나는 밥을") = 0.25
  P("먹어라" | "나는 밥을") = 0.10

  → 이전 토큰들이 주어졌을 때 다음 토큰의 조건부 확률
  → 이것이 LLM의 핵심 학습 목표
```

## 확률 분포 (Probability Distribution)

```
이산 분포:
  특정 값들에 확률이 할당됨
  예: 주사위 각 면 = 1/6

연속 분포:
  연속적인 값의 범위에 확률이 분포
  정규분포(가우시안): 평균 중심, 좌우 대칭 종 모양

AI에서:
  가중치 초기화: 정규분포로 무작위 초기화
  노이즈 추가: 정규분포 노이즈로 데이터 증강
  VAE, Diffusion 모델: 확률 분포 기반 생성
```

## Softmax

```
임의의 실수 벡터 → 확률 분포로 변환 (합 = 1)

입력: [2.0, 1.0, 0.5]
Softmax 계산:
  e^2.0 = 7.39
  e^1.0 = 2.72
  e^0.5 = 1.65
  합계  = 11.76

출력: [7.39/11.76, 2.72/11.76, 1.65/11.76]
     = [0.629, 0.231, 0.140]     ← 합 = 1.0

LLM의 최종 출력층에서 128,000개 토큰에 대해 Softmax 적용
```

### Temperature와 Softmax

```
Temperature T로 Softmax 조절:
  Softmax(x/T)

T < 1 (낮은 Temperature, 예: 0.1):
  확률 분포가 날카로워짐 (최고 확률 토큰에 집중)
  → 결정론적, 일관된 출력
  → 이 프로젝트: Temperature=0.1 (보안 분석 일관성)

T > 1 (높은 Temperature, 예: 1.5):
  확률 분포가 평평해짐 (다른 토큰도 선택될 가능성)
  → 창의적, 다양한 출력
  → 소설, 시 창작에 적합
```

## 엔트로피와 Cross-Entropy 손실

### 엔트로피 (Entropy)

```
정보의 불확실성 측도

H(P) = -Σ P(x) × log P(x)

확실한 분포 (한쪽에 쏠림): 낮은 엔트로피
불확실한 분포 (고름):      높은 엔트로피

예:
  [1.0, 0, 0, 0] → 엔트로피 = 0 (완전히 확실)
  [0.25, 0.25, 0.25, 0.25] → 엔트로피 최대 (완전히 불확실)
```

### Cross-Entropy 손실

```
예측 분포 Q와 실제 분포 P의 차이:
  H(P, Q) = -Σ P(x) × log Q(x)

분류 학습에서:
  P = 정답 (예: [0, 1, 0] → "공격"이 정답)
  Q = 모델 예측 (예: [0.1, 0.7, 0.2])

  손실 = -log(0.7) = 0.36

  모델이 정답을 높은 확률로 예측할수록 손실 감소
  → 학습 목표: Cross-Entropy 손실 최소화
```

## 베이즈 정리 (Bayes' Theorem)

```
P(A|B) = P(B|A) × P(A) / P(B)

AI 적용:
  나이브 베이즈 분류기 (전통 ML)
  베이지안 최적화 (하이퍼파라미터 탐색)
  사전 확률 + 증거 → 사후 확률 업데이트

보안 예시:
  P(공격 | "Invalid user" 로그) =
    P("Invalid user" | 공격) × P(공격) / P("Invalid user")
```

## 샘플링 (Sampling)

```
LLM이 다음 토큰을 선택하는 방법

Greedy (탐욕적):
  항상 확률 최고 토큰 선택
  → 반복적, 창의성 없음

Temperature Sampling:
  확률 분포에서 무작위 샘플링
  → 다양성 확보, Temperature로 조절

Top-k Sampling:
  확률 상위 k개 중에서만 샘플링
  → 너무 낮은 확률 토큰 배제

Top-p (Nucleus) Sampling:
  누적 확률이 p가 될 때까지의 토큰 중 샘플링
  → 동적으로 후보 수 조절

이 프로젝트:
  Temperature=0.1 → 거의 Greedy에 가까움
  보안 분석의 일관성 우선
```
