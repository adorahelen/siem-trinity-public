## 정보량 (Information Content)

```
"드문 사건일수록 더 많은 정보를 담는다"

I(x) = -log₂ P(x)   (단위: 비트)

예시:
  "내일 태양이 뜬다" P=1.0 → I = -log₂(1) = 0 비트 (정보 없음)
  "내일 눈이 온다"   P=0.1 → I = -log₂(0.1) ≈ 3.32 비트
  "내일 지진 발생"   P=0.001 → I = -log₂(0.001) ≈ 9.97 비트

LLM 적용:
  드물게 등장하는 토큰 → 높은 정보량
  자주 등장하는 토큰 → 낮은 정보량
```

---

## 엔트로피 (Entropy)

```
평균 정보량 = 불확실성의 측도

H(X) = -Σ P(x) × log₂ P(x)

예시:
  동전 (앞/뒤 각 50%): H = -0.5×log₂(0.5) × 2 = 1 비트
  편향 동전 (앞 99%, 뒤 1%): H ≈ 0.08 비트 (거의 확실)

LLM 학습:
  다음 토큰을 예측하는 것 = 엔트로피 최소화
  잘 학습된 LLM: 다음 토큰에 대한 불확실성이 낮음
```

---

## Cross-Entropy — 손실 함수의 본질

```
정의:
  실제 분포 P를 예측 분포 Q로 부호화할 때의 평균 비트 수

H(P, Q) = -Σ P(x) × log Q(x)

= H(P) + KL(P||Q)
  실제 엔트로피 + 예측이 얼마나 틀렸는가

LLM 학습:
  P = 실제 다음 토큰 (정답 분포)
  Q = 모델 예측 분포

  완벽한 예측: H(P,Q) = H(P) (KL=0)
  나쁜 예측:   H(P,Q) >> H(P) (KL 큼)

  → Cross-Entropy를 최소화하는 것
     = 예측 분포를 실제 분포에 최대한 가깝게 만드는 것
```

## Perplexity — LLM 성능 지표

```
정의:
  Perplexity = 2^H(P,Q)
  = Cross-Entropy의 지수

의미:
  "모델이 다음 토큰을 예측할 때 평균적으로 몇 개 중 하나를 고르는 수준인가"

낮을수록 좋음:
  Perplexity = 1: 완벽한 예측 (불가능)
  Perplexity = 10: 10개 중 하나
  Perplexity = 100: 100개 중 하나 (나쁜 모델)

비교:
  GPT-2 (2019): Perplexity ~35 (WikiText 기준)
  GPT-3 (2020): Perplexity ~20
  llama3.1:8b : Perplexity ~8~10 수준
```

## BPE (Byte Pair Encoding) — 토크나이저

```
정보이론 기반 토크나이저 알고리즘

원리:
  자주 등장하는 문자 쌍을 하나의 토큰으로 병합
  → 적은 토큰 수로 더 많은 정보 표현 (압축)

예시:
  "aaabdaaabac"
  → "aa"가 자주 등장 → "Z"로 대체: "ZabdZabac"
  → "Za"가 자주 등장 → "Y"로 대체: "YbdYbac"
  ...

LLM 어휘:
  llama3.1: 128,000 토큰 (BPE로 구성)
  자주 쓰는 단어 → 1 토큰
  희귀 단어 → 여러 서브워드 토큰으로 분리
```

## 지식 증류 (Knowledge Distillation)

```
큰 모델(Teacher)의 지식을 작은 모델(Student)에 전달

방법:
  Teacher의 Softmax 출력(확률 분포) → Student 학습 목표
  단순 정답 레이블이 아닌 "소프트 레이블" 사용

정보이론 관점:
  Teacher의 출력 분포에는 레이블보다 더 많은 정보 포함
  예: "고양이" 이미지
  레이블: [0, 0, 1, 0, ...]  ← 정보 빈약
  Teacher: [0.02, 0.15, 0.70, 0.08, ...] ← "개랑 약간 비슷함" 정보 포함

실제 적용:
  GPT-4 → 작은 모델로 증류
  llama 70B → 8B로 증류
  → 성능 손실 최소화하며 크기 축소
```
