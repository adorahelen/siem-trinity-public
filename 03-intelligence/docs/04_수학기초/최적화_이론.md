# 최적화 이론 (Optimization Theory)

> 작성일: 2026-03-20
> 경사 하강법 너머 — AI 학습의 수학적 심화

---

## 최적화란

```
목적 함수(objective function)를 최소화 또는 최대화하는
파라미터를 찾는 과정

딥러닝:
  목적 함수 = 손실 함수 (Loss)
  파라미터 = 신경망 가중치
  목표 = 손실 최소화
```

---

## 볼록 vs 비볼록 최적화

```
볼록 함수 (Convex):
  어디서 시작해도 경사 하강으로 전역 최솟값 도달 보장
  예: 선형 회귀, 로지스틱 회귀의 손실 함수

비볼록 함수 (Non-convex):
  여러 개의 극솟값 존재
  → 경사 하강이 지역 최솟값에 갇힐 수 있음

딥러닝의 손실 함수:
  비볼록 (수억 개 파라미터의 복잡한 지형)
  그럼에도 잘 동작하는 이유:
  → 고차원에서는 지역 최솟값이 전역 최솟값과 품질이 비슷
  → 안장점(saddle point)은 있지만 실제로 학습이 거기 갇히는 경우 드묾
```

## 2차 최적화 (Second-Order Methods)

```
경사 하강법 (1차):
  기울기(1차 미분)만 사용
  → 방향은 알지만 최적 보폭을 모름

2차 최적화:
  헤시안(Hessian) 행렬 (2차 미분) 활용
  → 곡률 정보로 더 정확한 보폭 결정
  → 더 빠른 수렴

대표: Newton's Method, L-BFGS

딥러닝에서 쓰지 않는 이유:
  파라미터 n개 → 헤시안 n×n 행렬
  80억 파라미터 → 80억×80억 행렬 = 저장/계산 불가
  → 1차 방법(Adam 등)이 실용적 대안
```

## 학습률 최적화 심화

### Momentum

```
이전 기울기 방향을 "관성"으로 유지

문제:
  경사 하강은 진동하며 느리게 수렴

해결:
  이전 업데이트 방향의 일부를 현재에 더함
  → 진동 감소, 수렴 가속
  → 안장점 탈출에도 도움

Adam의 m1 항이 Momentum 역할
```

### 적응형 학습률 (Adaptive Learning Rate)

```
문제:
  모든 파라미터에 같은 학습률 적용
  → 자주 업데이트되는 파라미터는 과대, 드문 파라미터는 과소

해결 (Adam):
  각 파라미터마다 학습률 자동 조절
  자주 등장: 학습률 낮춤
  드물게 등장: 학습률 높임

→ 희소한 피처에도 효과적 학습
→ NLP, 임베딩에서 특히 효과적
```

## 손실 함수 심화

### KL Divergence

```
두 확률 분포 P와 Q의 차이 측정

KL(P||Q) = Σ P(x) × log(P(x)/Q(x))

비대칭:
  KL(P||Q) ≠ KL(Q||P)

AI 적용:
  VAE (변분 오토인코더): 잠재 공간 정규화
  RLHF: LLM이 원본에서 너무 멀리 벗어나지 않도록 제약
  지식 증류(Distillation): 큰 모델 → 작은 모델 지식 전달
```

### Contrastive Loss

```
유사한 것은 가깝게, 다른 것은 멀게

임베딩 학습에 사용:
  "SSH 공격 로그" ↔ "SSH 공격 쿼리" → 가깝게
  "SSH 공격 로그" ↔ "점심 메뉴 쿼리" → 멀게

nomic-embed-text 같은 임베딩 모델이 이 방식으로 학습됨
→ 검색 품질의 수학적 기반
```

## 정규화의 수학적 의미

```
일반적 최적화:
  min L(θ)

정규화 추가:
  min L(θ) + λ·R(θ)

R(θ): 정규화 항 (파라미터 복잡도 패널티)
λ: 정규화 강도 (하이퍼파라미터)

L1 정규화: R(θ) = Σ|θi|   → 희소 해 (일부 파라미터 0)
L2 정규화: R(θ) = Σθi²    → 파라미터 작게 유지
```
