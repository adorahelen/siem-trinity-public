# 미적분 (Calculus) — AI의 수학적 기반 ②

> 작성일: 2026-03-20
> 기울기와 편미분 — 역전파의 수학적 본질

---

## 왜 AI에 미적분이 필요한가

```
역전파(Backpropagation)의 본질:
  "가중치를 어느 방향으로 얼마나 바꿔야 손실이 줄어드는가"
  = 손실 함수를 각 가중치에 대해 편미분

미분 없이는 학습 불가능
```

---

## 미분 (Derivative)

```
정의: 함수가 입력에 따라 얼마나 빠르게 변하는가
      = 순간 변화율 = 접선의 기울기

f(x) = x²  → f'(x) = 2x

x=1 에서의 기울기: f'(1) = 2
  → x를 1만큼 늘리면 f(x)는 약 2만큼 늘어남

x=3 에서의 기울기: f'(3) = 6
  → x=3 근처에서는 변화가 더 가파름
```

---

## 편미분 (Partial Derivative)

```
변수가 여러 개일 때, 하나의 변수에 대해서만 미분

f(w1, w2) = w1² + w1·w2 + w2²

∂f/∂w1 = 2·w1 + w2   (w2는 상수 취급)
∂f/∂w2 = w1 + 2·w2   (w1는 상수 취급)

신경망:
  손실 함수 L(w1, w2, ..., w80억)
  → 각 파라미터에 대한 편미분
  → 이것이 역전파에서 계산하는 "기울기"
```

---

## 기울기 (Gradient)

```
정의: 모든 편미분을 모아놓은 벡터

∇L = [∂L/∂w1, ∂L/∂w2, ..., ∂L/∂wn]

의미: 손실이 가장 빠르게 증가하는 방향

경사 하강법:
  손실을 줄이려면 기울기 반대 방향으로 이동
  w_new = w_old - 학습률 × ∇L
```

---

## 연쇄 법칙 (Chain Rule)

```
역전파의 핵심 수학

합성 함수의 미분:
  f(g(x)) 의 미분 = f'(g(x)) × g'(x)

신경망 예시:
  Loss = L(y_pred)
  y_pred = f(z)
  z = w·x + b

  ∂Loss/∂w = ∂Loss/∂y_pred × ∂y_pred/∂z × ∂z/∂w
            = L'(y_pred)    × f'(z)        × x

역전파는 연쇄 법칙을 출력층부터 입력층 방향으로 반복 적용
```

---

## 경사 하강법 (Gradient Descent)

```
직관: 산에서 내려갈 때 가장 가파른 방향(기울기)의 반대로 발을 내딛기

수식:
  θ_new = θ_old - α × ∇L(θ)
  α = 학습률 (step size)

반복:
  현재 위치에서 기울기 계산
  → 기울기 반대 방향으로 이동
  → 손실이 최솟값에 수렴할 때까지 반복
```

### 지역 최솟값 문제

```
손실 함수가 복잡한 형태라면:
  여러 개의 골짜기(local minimum) 존재
  → 기울기 0이지만 전역 최솟값(global minimum)이 아닐 수 있음

딥러닝에서의 대응:
  Adam 같은 적응형 옵티마이저
  무작위 초기화 (여러 위치에서 시작)
  큰 모델에서는 지역 최솟값이 전역 최솟값과 비슷한 경우 많음
```

## 적분 (Integration)

```
미분의 반대 연산 — AI에서는 직접 쓰임이 적음

주로 쓰이는 곳:
  확률 분포의 면적 계산
  KL Divergence (두 분포 간 차이) 계산 → RLHF에서 사용
  정규화 상수 계산
```

## 미적분이 AI에서 어디에 쓰이는가

| 개념 | AI 적용 |
|------|---------|
| 미분 | 역전파에서 손실 함수의 기울기 계산 |
| 편미분 | 각 파라미터에 대한 기울기 |
| 연쇄 법칙 | 역전파 전체 과정 |
| 경사 하강법 | 파라미터 업데이트 |
| 적분 | 확률 분포 정규화, KL Divergence |

## 이 프로젝트와의 관계

```
이 프로젝트:
  미적분 직접 사용: 없음
  (이미 학습된 모델을 추론만 하므로)

미적분이 사용된 곳:
  llama3.1:8b 사전학습 시 Meta가 수행
  → 수조 토큰에 대해 역전파 반복
  → 연쇄 법칙으로 80억 파라미터 기울기 계산
  → Adam으로 업데이트

만약 파인튜닝 한다면:
  미적분 연산이 GPU에서 자동으로 수행 (PyTorch autograd)
  직접 손으로 계산할 필요 없음
  → 프레임워크가 자동 미분(autograd) 처리
```
