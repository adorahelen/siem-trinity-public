# 선형대수 (Linear Algebra) — AI의 수학적 기반 ①

> 작성일: 2026-03-20
> 벡터와 행렬 — Attention, 임베딩, 가중치 업데이트의 수학적 본질

---

## 왜 AI에 선형대수가 필요한가

```
딥러닝의 모든 연산은 행렬 곱셈으로 이루어짐

신경망 레이어:
  출력 = 활성화함수(가중치행렬 × 입력벡터 + 편향벡터)
  Y = f(W · X + b)

Attention:
  Attention(Q, K, V) = Softmax(QKᵀ / √d) · V
  → Q, K, V 모두 행렬
  → 행렬 곱, 전치, 스케일링, Softmax

임베딩:
  "SSH 공격" → [0.23, -0.87, 0.45, ..., 0.67]
  → 768차원 벡터 = 768개 숫자의 배열
```

---

## 벡터 (Vector)

```
정의: 크기와 방향을 가진 수의 배열

1차원: [3]          (스칼라, 방향 없음)
2차원: [3, 4]       (2D 평면의 한 점)
768차원: [0.23, -0.87, ..., 0.67]  (임베딩 벡터)

AI에서 벡터의 의미:
  단어/문장 → 고차원 벡터 공간의 한 점
  의미가 비슷한 단어 → 가까운 점
```

### 벡터 연산

```
덧셈:   [1, 2] + [3, 4] = [4, 6]
스케일: 2 × [1, 2] = [2, 4]

내적 (Dot Product):
  [1, 2] · [3, 4] = 1×3 + 2×4 = 11
  두 벡터가 얼마나 같은 방향을 가리키는가
  → Attention에서 Q·K 계산의 본질
```

### 코사인 유사도

```
두 벡터 간 각도의 코사인
= 내적 / (||벡터1|| × ||벡터2||)

범위: -1 (완전 반대) ~ 0 (무관) ~ 1 (완전 동일)

임베딩 검색:
  "SSH 공격" 벡터와 로그 벡터들의 코사인 유사도 계산
  → 가장 높은 것 = 가장 관련 있는 로그
  → ChromaDB가 내부적으로 하는 것
```

## 행렬 (Matrix)

```
정의: 수를 직사각형 형태로 배열

2×3 행렬:
  [1, 2, 3]
  [4, 5, 6]

AI에서 행렬의 의미:
  가중치 행렬 W: 레이어의 학습된 파라미터 전체
  입력 배치: 여러 샘플을 동시에 처리
```

### 행렬 곱셈

```
(m×n) × (n×p) = (m×p)

[1, 2]   [5, 6]   [1×5+2×7, 1×6+2×8]   [19, 22]
[3, 4] × [7, 8] = [3×5+4×7, 3×6+4×8] = [43, 50]

신경망 레이어 하나:
  가중치 행렬 W (hidden_size × input_size)
  × 입력 벡터 X (input_size × 1)
  = 출력 벡터 (hidden_size × 1)

GPU가 행렬 곱셈을 병렬로 처리 → 딥러닝이 빠른 이유
```

## 전치 (Transpose)

```
행과 열을 뒤집음

[1, 2, 3]ᵀ   [1]
             [2]
             [3]

Attention에서:
  Q · Kᵀ → Q와 K의 유사도 행렬 계산
  Kᵀ (Key의 전치)로 모든 Q-K 쌍 내적을 한 번에 계산
```

---

## 고유값과 고유벡터 (Eigenvalue/Eigenvector)

```
행렬 A와 벡터 v에 대해:
  A·v = λ·v (λ는 스칼라)
  → v는 A의 고유벡터, λ는 고유값

AI 적용:
  PCA (차원 축소): 데이터의 주요 방향 = 공분산 행렬의 고유벡터
  → 고차원 데이터를 핵심 방향만 남기고 압축
```

## 선형대수가 AI에서 어디에 쓰이는가

| 개념 | AI 적용 |
|------|---------|
| 벡터 내적 | Attention Q·K 유사도, 코사인 유사도 |
| 행렬 곱 | 모든 신경망 레이어 연산 |
| 전치 | Attention Kᵀ 계산 |
| 고유벡터 | PCA 차원 축소 |
| 노름(norm) | 벡터 크기, 코사인 유사도 분모 |
| 역행렬 | 일부 최적화 알고리즘 |

## 이 프로젝트의 선형대수

```
nomic-embed-text가 하는 일:
  "SSH 공격" → 768차원 벡터 (행렬 곱 수천 번)

ChromaDB가 하는 일:
  질문 벡터 · 저장된 벡터들 = 코사인 유사도 계산
  → 내적 연산

Attention이 하는 일:
  Q · Kᵀ → 유사도 행렬 → Softmax → · V
  → 세 번의 행렬 연산
```
