# AI 엔지니어링 역사 — 실무/제품 중심

> 작성일: 2026-03-19
> 이론(논문) 중심이 아닌, 실제 엔지니어링 트렌드 변화 기록

---

## 한눈에 보는 흐름

```
2017 ─ Transformer 등장
2020 ─ GPT-3 → "거대 모델" 시대 시작
2022 ─ ChatGPT → 일반인도 LLM 사용
2023 ─ 오픈소스 LLM 폭발 + LangChain + 벡터DB 붐
2024 ─ sLLM 대세 + RAG 표준화 + Agent 등장
2025 ─ Multi-Agent + MCP + 로컬 AI 일상화
```

---

## 2017 — Transformer 등장

**사건:** Google "Attention is All You Need" 논문 발표

**엔지니어링 영향:**
- 기존 RNN/LSTM 기반 NLP가 사실상 대체됨
- "어텐션 메커니즘"으로 문맥 이해 능력 비약적 향상
- 이후 모든 LLM의 기반 구조가 됨

```
이전: RNN → 순서대로 읽음 (긴 문장에서 앞부분 망각)
이후: Transformer → 전체를 동시에 봄 (문맥 전체 파악)
```

---

## 2018~2020 — BERT, GPT 시대

**주요 모델:** BERT (Google, 2018), GPT-1/2/3 (OpenAI, 2018~2020)

**엔지니어링 트렌드:**
- NLP 태스크(번역, 분류, 요약)에 Pre-trained 모델 Fine-tuning이 표준
- GPT-3 (175B) 등장으로 "스케일이 곧 성능"이라는 패러다임 확립
- API로 LLM 호출하는 첫 상업적 서비스 등장

**한계:**
- 모델이 너무 커서 로컬 실행 불가
- OpenAI API 종속 구조

---

## 2022 — ChatGPT 충격 + 오픈소스 반격

**사건:** ChatGPT 출시 (2022.11) → 역대 가장 빠른 사용자 1억 명 달성

**엔지니어링 영향:**
- RLHF(인간 피드백 강화학습)로 "대화하는 LLM" 실현
- 모든 IT 기업이 LLM 통합을 최우선 과제로

**오픈소스 반격:**
- Meta, LLaMA 공개 (2023.2) → 누구나 모델 다운로드 가능
- Stable Diffusion 오픈소스 → 이미지 생성 민주화
- Alpaca, Vicuna 등 LLaMA 기반 파생 모델 폭발

```
이전: OpenAI API 종속 (돈 내고 써야 함)
이후: 로컬에서 직접 실행 가능 (무료)
```

---

## 2023 — LangChain + 벡터DB + RAG 붐

**"어떻게 LLM을 제품에 쓸 것인가"의 해답이 정립된 해**

**주요 사건:**
- **LangChain** GitHub Star 6만 돌파 → LLM 앱 개발 표준 프레임워크
- **ChromaDB, Pinecone, Weaviate** 등 벡터 DB 스타트업 급성장
- **RAG** 패턴이 "LLM + 사내 데이터" 표준 구조로 자리잡음
- **GPT-4** 출시 → 멀티모달(이미지 이해) 첫 등장

**엔지니어링 트렌드:**
```
문제: LLM은 최신 정보 / 사내 데이터를 모름
해결: RAG — 외부 DB에서 검색 후 컨텍스트 주입
도구: LangChain(파이프라인) + ChromaDB(벡터저장) + Ollama(로컬서빙)
```

**이 프로젝트가 정확히 이 트렌드의 산물**

---

## 2024 — sLLM 대세 + Agent 등장

**"작지만 강한 모델"과 "스스로 행동하는 AI"의 해**

### sLLM 대세

| 모델 | 파라미터 | 특징 |
|------|---------|------|
| Llama 3 (8B/70B) | 8B | Meta, 오픈소스 최강자 |
| Phi-3 (3.8B) | 3.8B | Microsoft, 작지만 강함 |
| Gemma (2B/7B) | 7B | Google, 경량화 |
| Qwen2.5 (7B/14B) | 14B | Alibaba, 다국어 강점 |
| Mistral 7B | 7B | 유럽 오픈소스 |

**왜 sLLM이 대세가 됐나:**
```
GPT-4급 대형 모델: 성능 최고, 비용 높음, 로컬 불가
sLLM + RAG:        성능 충분, 비용 거의 없음, 로컬 가능
             → 실용적인 선택이 sLLM + RAG
```

### Agent 등장

- **AutoGPT** (2023말~2024): 목표만 주면 스스로 계획·실행
- **LangGraph**: LangChain의 Agent 전용 프레임워크
- **AutoGen** (Microsoft): 멀티 에이전트 협업
- **CrewAI**: 역할 분담 멀티 에이전트

**엔지니어링 트렌드:**
```
이전: 사용자 질문 → LLM 답변 (수동)
이후: 사용자 목표 → Agent가 계획·검색·실행·보고 (자동)
```

## 2025 — Multi-Agent + MCP + 로컬 AI 일상화

**"AI가 혼자서 일한다"는 개념이 현실화**

### MCP (Model Context Protocol)

Anthropic이 발표한 AI ↔ 외부 도구 연결 표준 프로토콜.

```
이전: 각 서비스마다 LangChain Tool을 직접 구현
이후: MCP 표준으로 연결 → Slack, GitHub, DB 등 자동 연동
```

Claude Desktop, Cursor, VSCode 등에서 이미 적용 중.

### 로컬 AI 일상화

- Ollama 다운로드 수천만 건
- MacBook, 일반 PC에서 14B 모델 실행이 "당연한" 수준
- Apple Silicon(M 시리즈)의 Metal 가속이 핵심 역할
