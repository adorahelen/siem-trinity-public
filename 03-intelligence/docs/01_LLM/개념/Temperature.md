# Temperature — LLM 창의성 조절 파라미터

> 작성일: 2026-03-19
> 관련 파일: `rag_chain.py` — `OllamaLLM(temperature=0.1)`

---

## Temperature란?

LLM이 다음 단어를 선택할 때 **얼마나 다양하게 선택할지** 조절하는 값.
범위: **0.0 ~ 2.0** (일반적으로 0.0 ~ 1.0 사용)

---

## 직관적 이해

```
질문: "SSH 공격을 막으려면?"

Temperature=0.0 (결정론적):
  → 항상 같은 답변: "fail2ban을 설정하십시오."

Temperature=1.0 (창의적):
  → 매번 다른 표현: "방화벽 규칙을 수정하거나, IDS를 강화하거나..."
  → 때로는 예상치 못한 창의적 답변

Temperature=2.0 (과도하게 창의적):
  → 횡설수설, 관련 없는 단어 조합
```

---

## 값에 따른 동작 차이

| Temperature | 특성 | 적합한 용도 |
|------------|------|-----------|
| **0.0** | 완전히 결정론적, 항상 동일 | 코드 생성, JSON 파싱 |
| **0.1** | 거의 결정론적, 약간의 유연성 | **보안 분석 ← 이 프로젝트** |
| **0.3~0.5** | 일관성 + 자연스러운 표현 | 요약, 번역 |
| **0.7~1.0** | 창의적, 다양한 표현 | 글쓰기, 브레인스토밍 |
| **1.5+** | 매우 창의적, 예측 불가 | 창작, 시, 아이디어 발산 |

---

## 이 프로젝트에서 0.1로 설정한 이유

```python
llm = OllamaLLM(temperature=0.1)
```

보안 분석은 **일관성과 정확성**이 핵심:

```
❌ Temperature 높음:
  "공격 IP는 아마 218.92.x.x 대역일 수도 있고, 혹은..."
  → 불필요한 추측, 매번 다른 답변

✅ Temperature=0.1:
  "공격 IP는 218.92.0.23입니다. fail2ban에 의해 차단되었습니다."
  → 로그에 근거한 일관된 답변
```

할루시네이션 억제에도 도움: 창의적 생성을 줄여 근거 없는 내용 생성 감소.

## Top-p (nucleus sampling) — Temperature와 함께 쓰는 파라미터

```python
# Ollama에서 추가 가능
llm = OllamaLLM(
    temperature=0.1,
    top_p=0.9,      # 상위 90% 확률의 단어만 후보로
    top_k=40,       # 상위 40개 단어만 후보로
)
```

보안 분석에서는 temperature=0.1 만으로 충분합니다.
