## 비용 구조 비교

### 클라우드 LLM (OpenAI, Anthropic 등)

```
비용 = 입력 토큰 수 × 입력 단가 + 출력 토큰 수 × 출력 단가

GPT-4o 기준:
  입력: $2.50 / 1M tokens
  출력: $10.00 / 1M tokens

월 1,000회 질의, 평균 2,000 tokens/회 가정:
  = 2,000,000 tokens × $2.50/M = $5.00/월 (입력만)
  + 출력 포함 시 약 $15~30/월
```

### 로컬 LLM (이 프로젝트 = Ollama)

```
초기 비용: 모델 다운로드 (llama3.1:8b = 4.9GB, 1회만)
운영 비용: $0 (전기세 제외)
API 키: 불필요
데이터 외부 전송: 없음
```

| 보고서 작성 | ✅ 충분 | ❌ 비쌈 |
| 실시간 대화 | ✅ 빠름 | ⚠️ 지연 있음 |

## 하이브리드 전략 (2024~2025 트렌드)

```
라우터 (경량 모델이 판단):
  단순 질문 ──────────────→ 로컬 llama3.1:8b (무료, 빠름)
  복잡한 추론 질문 ────────→ Claude API (유료, 정확)
  민감 데이터 포함 ────────→ 로컬 (데이터 보안)
  민감 데이터 없음 + 복잡  →  클라우드
```

## 이 프로젝트 비용 분석

```
현재:
  모델 비용:    $0 (Ollama 로컬)
  API 비용:     $0
  서버 비용:    $0 (맥북 로컬)
  전기세:       약 15W × 사용시간 (무시 가능)

vs 클라우드로 운영 시:
  보안 로그는 외부 전송 불가 → 클라우드 옵션 자체가 없음
  → 로컬이 유일한 선택
```
