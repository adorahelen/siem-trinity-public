## 이 프로젝트 포지셔닝

```
현재                            업그레이드 옵션
──────────────────────────────────────────────────
llama3.1:8b  (답변 생성)   →   qwen2.5:14b  ← 이미 보유, 한국어↑
nomic-embed-text (임베딩)  →   변경 비추천 (안정적)

MacBook M3 16GB 한계선: ~30B (4bit 양자화 기준)
```

## 양자화(Quantization)란?

모델 가중치를 32bit → 4bit로 압축해서 메모리를 1/8로 줄이는 기술.
Ollama는 기본적으로 양자화된 버전(`.gguf`)을 사용하므로,
70B 모델도 MacBook에서 느리지만 실행은 가능합니다.

| 양자화 | 메모리 | 품질 손실 |
|--------|--------|---------|
| Q8 (8bit) | 1/4 | 거의 없음 |
| Q4 (4bit) | 1/8 | 약간 |
| Q2 (2bit) | 1/16 | 큼 |
