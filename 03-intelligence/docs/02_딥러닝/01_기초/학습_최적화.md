# 학습 최적화 (Optimizer & Training Techniques)

> 작성일: 2026-03-20
> 역전파로 기울기를 구한 후, 어떻게 가중치를 효율적으로 업데이트하는가

---

## 옵티마이저 (Optimizer)

가중치 업데이트 전략. 기울기를 어떻게 활용해 가중치를 수정할지 결정.

### SGD (Stochastic Gradient Descent)

```
전체 데이터 중 무작위로 1개(또는 소량) 뽑아 기울기 계산 후 업데이트

장점: 빠름, 메모리 효율
단점: 방향이 불안정 (노이즈 많음)

비유: 눈 감고 산에서 내려가기 — 매번 조금씩 방향이 달라짐
```

### Adam (Adaptive Moment Estimation)

```
현재 가장 많이 쓰이는 옵티마이저
"자주 등장한 파라미터는 적게, 드물게 등장한 파라미터는 많이 업데이트"

장점: 학습률 자동 조절, 빠른 수렴, 안정적
단점: 메모리 사용량 SGD의 2배

LLM 학습: Adam 또는 AdamW (Weight Decay 추가) 사용
```

### AdamW

```
Adam + Weight Decay (L2 정규화 효과)
LLM 학습의 표준 옵티마이저
llama, GPT 계열 모두 AdamW 사용
```

## 배치 (Batch)

```
한 번의 역전파에 사용하는 데이터 수

Full Batch:
  전체 데이터로 한 번에 기울기 계산
  → 정확하지만 메모리 부족 위험

Mini-batch (일반적):
  32, 64, 128개씩 나눠서 학습
  → 속도와 안정성 균형
  → 현대 딥러닝의 표준

Stochastic (1개씩):
  빠르지만 너무 불안정
```

---

## 에포크 (Epoch)

```
전체 학습 데이터를 한 번 다 사용한 것 = 1 에포크

일반적으로 수십~수백 에포크 반복
LLM 사전학습: 수조 토큰을 1~2 에포크
LLM 파인튜닝: 수만 건 데이터를 3~10 에포크
```

## 학습률 스케줄러

학습이 진행됨에 따라 학습률을 조절.

```
Warmup:
  처음에는 학습률을 0에서 서서히 올림
  → 초기 불안정한 학습 방지
  → LLM 학습에서 필수

Cosine Decay:
  Warmup 후 코사인 곡선으로 서서히 감소
  → LLM 학습 표준 스케줄

Step Decay:
  특정 에포크마다 학습률을 절반으로 줄임
  → 전통 CNN 학습에서 많이 사용
```

## 정규화 기법

과적합 방지 + 학습 안정화.

### Batch Normalization

```
각 레이어의 입력을 평균 0, 분산 1로 정규화
→ 기울기 소실/폭발 방지
→ 학습 안정화
→ 더 높은 학습률 사용 가능

주로: CNN, 전통 신경망에서 사용
```

### Layer Normalization

```
Batch가 아닌 각 샘플 내에서 정규화
→ 배치 크기에 무관

주로: Transformer (LLM)에서 사용
llama3.1, GPT 계열 모두 Layer Norm 사용
```

### Dropout

```
훈련 중 무작위로 일부 뉴런을 꺼버림 (확률 p)
→ 특정 뉴런에 과의존 방지
→ 과적합 억제
→ 추론 시에는 모든 뉴런 사용 (비율 조정)
```

## 학습 안정화 기법 요약

| 기법 | 목적 | LLM 적용 |
|------|------|---------|
| AdamW | 효율적 가중치 업데이트 | ✅ 표준 |
| Warmup | 초기 불안정 방지 | ✅ 필수 |
| Cosine Decay | 학습률 점진적 감소 | ✅ 표준 |
| Layer Norm | 레이어 간 분포 안정화 | ✅ 필수 |
| Gradient Clipping | 기울기 폭발 방지 | ✅ 필수 |
| Dropout | 과적합 방지 | 파인튜닝 시 사용 |
