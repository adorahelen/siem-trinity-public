# 신경망 구조 (Neural Network)

> 작성일: 2026-03-20
> 딥러닝의 기본 단위 — 뉴런에서 레이어, 레이어에서 네트워크로

---

## 생물학적 뉴런 → 인공 뉴런

```
생물학적 뉴런:
  수상돌기 (입력 신호 수신)
      │
   세포체 (신호 합산, 임계값 초과 시 발화)
      │
  축삭돌기 (다음 뉴런으로 신호 전달)

인공 뉴런:
  입력값 x1, x2, x3
      │
  가중합 (w1*x1 + w2*x2 + w3*x3 + bias)
      │
  활성화 함수 (비선형 변환)
      │
  출력값
```

**가중치(weight):** 각 입력이 얼마나 중요한가
**편향(bias):** 뉴런이 얼마나 쉽게 활성화되는가
**활성화 함수:** 단순 합산을 비선형으로 변환 → 복잡한 패턴 학습 가능

---

## 활성화 함수

```
활성화 함수가 없으면:
  아무리 레이어를 쌓아도 수학적으로 선형 변환 하나와 동일
  → 복잡한 패턴 학습 불가

활성화 함수가 있으면:
  비선형성 추가 → 깊은 레이어가 의미를 가짐
```

| 함수 | 특징 | 주로 사용 |
|------|------|---------|
| **ReLU** | 0 이하 → 0, 0 초과 → 그대로 | 은닉층 기본값 |
| **Sigmoid** | 출력 0~1 (확률) | 이진 분류 출력층 |
| **Softmax** | 출력 합이 1 (확률 분포) | 다중 분류 출력층 |
| **GELU** | ReLU의 부드러운 버전 | Transformer (LLM) |

## 레이어 구조

```
입력층 (Input Layer)
  → 데이터를 그대로 받음
  → 학습 파라미터 없음

은닉층 (Hidden Layer)
  → 패턴을 추출하고 변환
  → 레이어가 깊을수록 추상적 특징 학습
  → 이 레이어가 많으면 "딥"러닝

출력층 (Output Layer)
  → 최종 예측값 출력
  → 분류: Softmax (확률)
  → 회귀: 활성화 함수 없음 (수치 그대로)
```

---

## 깊이(Depth)가 왜 중요한가

```
얕은 네트워크 (레이어 1~2개):
  선, 곡선 같은 단순 패턴만 학습

깊은 네트워크 (레이어 수십~수백 개):
  1층: 픽셀 엣지 감지
  2층: 선과 곡선 조합
  3층: 눈, 코, 입 같은 부분 특징
  4층: 얼굴 전체 인식

LLM (수백 레이어):
  낮은 층: 단어, 철자 패턴
  중간 층: 문법, 구문 구조
  높은 층: 의미, 맥락, 논리
```

---

## 파라미터 수가 왜 중요한가

```
파라미터 = 모든 레이어의 (가중치 + 편향) 합계

전통 ML (랜덤포레스트):   수백만 이하
소형 CNN (이미지 분류):   수백만 ~ 수천만
GPT-2:                  15억 (1.5B)
llama3.1:8b:            80억 (8B)
GPT-4 (추정):           1.8조 (1.8T)

파라미터가 많을수록:
  → 더 복잡한 패턴 학습 가능
  → 더 많은 메모리 필요
  → GPU 없으면 현실적으로 불가능
```

## 전통 ML과 신경망 비교

| | 전통 ML | 신경망 (딥러닝) |
|--|---------|--------------|
| 피처 설계 | 사람이 직접 | 자동 학습 |
| 레이어 수 | 없음 (트리 깊이만) | 수십~수백 |
| 입력 형태 | 숫자 테이블 | 텍스트, 이미지, 음성 원문 |
| GPU 필요 | 없음 | 있음 |
| 해석 가능성 | 높음 | 낮음 (블랙박스) |
