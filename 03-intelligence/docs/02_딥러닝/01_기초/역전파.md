# 역전파 (Backpropagation)

> 작성일: 2026-03-20
> 신경망이 학습하는 핵심 원리 — 오차를 거꾸로 전파해 가중치를 수정

---

## 한 줄 정의

```
예측이 틀렸을 때, 얼마나 틀렸는지(오차)를
출력층 → 은닉층 → 입력층 방향으로 거꾸로 전파해
각 가중치가 오차에 기여한 정도를 계산하고 수정하는 과정
```

---

## 전체 학습 흐름

```
① 순전파 (Forward Pass)
   입력 → [레이어1] → [레이어2] → ... → 예측값 출력

② 손실 계산 (Loss Calculation)
   예측값 vs 정답 → 오차(손실) 계산

③ 역전파 (Backward Pass)
   출력층 ← [레이어2] ← [레이어1] ← 입력층
   각 가중치의 "기울기(gradient)" 계산

④ 가중치 업데이트
   가중치 = 가중치 - 학습률 × 기울기

① ~ ④ 반복 → 손실이 점점 줄어듦
```

---

## 손실 함수 (Loss Function)

예측이 얼마나 틀렸는지 수치화하는 함수.

```
분류 문제:
  Cross-Entropy Loss
  "정답 클래스의 확률이 높을수록 손실 감소"
  예: 정답이 "공격"인데 모델이 70% 확률로 맞추면 손실 낮음

회귀 문제:
  MSE (Mean Squared Error)
  "예측값과 실제값 차이의 제곱 평균"
```

---

## 기울기 (Gradient)란

```
기울기 = 가중치를 조금 바꿨을 때 손실이 얼마나 변하는가

기울기 양수 → 가중치 늘리면 손실 증가 → 가중치 줄여야 함
기울기 음수 → 가중치 줄이면 손실 증가 → 가중치 늘려야 함
기울기 0    → 이미 최적값 근처

가중치 업데이트:
  new_weight = old_weight - 학습률 × gradient
```

---

## 학습률 (Learning Rate)

```
학습률이 너무 크면:
  가중치가 너무 크게 변함 → 최적값을 건너뜀 → 발산

학습률이 너무 작으면:
  가중치가 조금씩만 변함 → 학습이 너무 느림
  → 지역 최솟값(local minimum)에 갇힐 수 있음

적절한 학습률:
  일반적으로 0.001 ~ 0.0001 범위
  학습 진행에 따라 점점 줄이는 방법 (Learning Rate Scheduler)
```

---

## 역전파가 어려운 이유

```
① 기울기 소실 (Vanishing Gradient)
   레이어가 깊어질수록 기울기가 0에 수렴
   → 초기 레이어는 학습이 거의 안 됨
   해결: ReLU 활성화 함수, Batch Normalization

② 기울기 폭발 (Exploding Gradient)
   기울기가 너무 커져 가중치가 폭발적으로 변함
   해결: Gradient Clipping (기울기 최대값 제한)

③ 계산량
   수백억 파라미터의 기울기를 동시에 계산
   → GPU 병렬 연산 없으면 불가능
```

## 전통 ML과 신경망 역전파 비교

전통 ML도 역전파(또는 유사한 최적화) 원리를 사용하지만 규모가 다릅니다.

```
로지스틱 회귀:
  파라미터 수: 수백 ~ 수천
  업데이트: CPU에서 초 단위

랜덤 포레스트:
  기울기 기반 아님 (정보이득 기반 분기)
  역전파 사용 안 함

XGBoost:
  기울기 기반 (2차 미분까지 활용)
  CPU에서 수 분 ~ 수 시간

llama3.1:8b 파인튜닝:
  파라미터 수: 80억
  업데이트: GPU 필수, 수 시간 ~ 수 일
```

## LLM 학습에서의 역전파

```
사전학습 (Pre-training):
  입력: "서울은 대한민국의 ___"
  정답: "수도"
  손실: 모델이 "수도"를 예측하지 못한 정도
  역전파: 80억 파라미터 전체 업데이트
  반복: 수조 토큰에 대해 반복

파인튜닝 (LoRA):
  전체 80억 파라미터 중 일부 레이어만 역전파
  → 계산량 대폭 절감
  → 이것이 LoRA의 핵심
```
