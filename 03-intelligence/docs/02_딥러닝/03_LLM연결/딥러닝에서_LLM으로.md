# 딥러닝에서 LLM으로 — 연결고리

> 작성일: 2026-03-20
> 전통 ML → 딥러닝 → LLM 의 진화 흐름과 각 단계의 핵심 돌파구

---

## 전체 진화 흐름

```
전통 ML (1980s~2010s)
  랜덤 포레스트, SVM, XGBoost
  사람이 피처 설계 / CPU / 수백만 파라미터
      │
      │ 돌파구: GPU 병렬 연산 + 대규모 데이터
      ▼
딥러닝 (2012~2017)
  CNN (이미지), RNN/LSTM (텍스트)
  피처 자동 학습 / GPU 필수 / 수천만~수억 파라미터
      │
      │ 돌파구: Attention (순차 처리 제거 + 병렬화)
      ▼
Transformer (2017~2020)
  BERT (이해), GPT (생성)
  텍스트 원문 입력 / 멀티 GPU / 수억~수십억 파라미터
      │
      │ 돌파구: 스케일 법칙 + RLHF
      ▼
LLM (2020~현재)
  GPT-3, ChatGPT, LLaMA, Claude
  범용 자연어 처리 / GPU 클러스터 / 수십억~수조 파라미터
```

---

## 각 단계의 핵심 돌파구

### 전통 ML → 딥러닝

```
돌파구: GPU 병렬 연산 + 충분한 데이터

2012년 AlexNet:
  GPU 2개로 CNN 학습 → ImageNet 오류율 10%p 감소
  증명한 것: "피처를 사람이 설계하지 않아도 된다"
             "깊은 네트워크가 복잡한 패턴을 학습한다"

핵심 변화:
  피처 엔지니어링 (사람) → 피처 학습 (모델 자동)
```

### 딥러닝 → Transformer

```
돌파구: Attention 메커니즘

2017년 "Attention is All You Need":
  RNN의 순차 처리 → 병렬 처리
  기울기 소실 → 직접 연결로 해결
  GPU 활용률 극대화

증명한 것: "순서가 있는 데이터도 병렬로 처리 가능"
           "먼 거리 의존성도 직접 포착 가능"
```

### Transformer → LLM

```
돌파구 1 — 스케일링 법칙
  더 많은 파라미터 + 데이터 + 계산 = 예측 가능한 성능 향상
  GPT-3 (175B): "크기만 키워도 in-context learning 가능"

돌파구 2 — RLHF (인간 피드백 강화학습)
  ChatGPT: 사람이 선호하는 답변을 강화학습으로 정렬
  "정확한 것" → "사람이 원하는 것"으로 목표 전환

돌파구 3 — 오픈소스
  LLaMA: 메타가 모델 공개 → 개인/스타트업도 LLM 사용 가능
          이 프로젝트의 llama3.1:8b
```

## 각 레이어가 배운 것

```
전통 ML:
  사람이 알려준 피처(IP, 포트, 패킷 수)를 조합
  → 수식으로 분류 경계 그음

딥러닝 (CNN):
  픽셀 → 엣지 → 형태 → 객체
  점점 추상적인 표현을 자동으로 학습

Transformer:
  토큰 → 단어 의미 → 문법 관계 → 문맥 → 의도
  언어의 계층적 구조를 스스로 학습

LLM (Large Scale):
  언어 → 세계 지식 → 추론 능력 → 지시 따르기
  충분히 크면 학습하지 않은 태스크도 수행 (Emergent Ability)
```

---

## 이 프로젝트의 좌표

```
Top-down 학습 관점:

Layer 1 (사용):  LLM + RAG
  → llama3.1:8b, nomic-embed-text, ChromaDB, LangChain
  → 이미 완성된 모델을 추론에만 활용

Layer 2 (이해):  딥러닝 (이 문서 섹션)
  → 신경망 구조, 역전파, CNN, RNN, Transformer
  → LLM이 어떻게 만들어졌는지 이해

Layer 3 (기초):  전통 ML
  → 랜덤 포레스트, SVM, 피처 엔지니어링
  → ML의 근본 원리 이해

"사용"에서 시작해 "이해"로, "이해"에서 "기초"로 내려가는 Top-down 방식
```

---

## Emergent Ability — 창발적 능력

```
LLM에서만 나타나는 현상

특정 규모 이상이 되면 학습하지 않은 능력이 갑자기 등장:
  번역 (학습 안 했는데 자동으로)
  수학 추론 (예시 없이 단계적 풀이)
  코드 생성 (여러 언어)
  퓨샷 학습 (예시 2~3개만으로 새 태스크 수행)

전통 ML에서는 없는 현상:
  랜덤 포레스트 1,000그루 → 100그루보다 좋지만 갑자기 새 능력 생기지 않음
  규모가 커지면 성능이 좋아지는 것뿐

이것이 LLM이 단순한 "더 큰 ML 모델"이 아닌 이유
```
