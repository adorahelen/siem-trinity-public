## 전통 RL의 한계

```
전통 RL (Q-Learning):
  상태(state)를 테이블로 관리
  상태 수가 많아지면 테이블 크기 폭발

예시:
  바둑: 가능한 상태 수 > 10^170
  → 테이블로 저장 불가능

해결: 신경망으로 Q 함수 근사 → Deep RL
```

---

## DQN (Deep Q-Network)

```
2013년 DeepMind — Atari 게임 학습으로 유명

핵심 아이디어:
  Q 테이블 → 신경망(Q-Network)으로 대체
  입력: 게임 화면(픽셀) → CNN → Q값 출력
  Q값: 각 행동을 했을 때 기대 보상

혁신:
  사람이 특징을 설계하지 않고
  픽셀 원본에서 직접 전략 학습
  → 49개 Atari 게임에서 사람 수준 달성
```

---

## Policy Gradient 방법

```
DQN: Q값(보상 추정)을 학습 → 행동 선택
Policy Gradient: 행동 정책(policy) 자체를 직접 학습

장점:
  연속적인 행동 공간에 적합 (로봇 제어, 자율주행)
  확률적 정책 학습 가능

대표 알고리즘: REINFORCE, Actor-Critic
```

---

## PPO (Proximal Policy Optimization)

```
현재 가장 널리 쓰이는 Deep RL 알고리즘

특징:
  안정적인 학습 (정책 업데이트를 너무 크게 하지 않음)
  구현이 비교적 단순
  연속/이산 행동 모두 지원

사용처:
  OpenAI Five (도타2 AI)
  ChatGPT의 RLHF (사람 선호도 강화학습)
  로봇 제어, 자율주행
```

---

## RLHF — LLM과 강화학습의 교차점

```
ChatGPT가 "사람처럼 대화"하게 만든 핵심 기술

과정:
  1. 사전학습된 LLM
  2. 사람이 여러 답변 중 선호도 평가
  3. 보상 모델(Reward Model) 학습
     → 사람이 좋아할 답변을 예측
  4. PPO로 LLM 파인튜닝
     → 보상 모델이 높은 점수를 주는 답변 생성하도록

결과:
  "정확한 것" → "사람이 원하는 것"으로 목표 전환
  유해 답변 감소, 지시 따르기 능력 향상
```

## 보안 자동 대응에의 적용 (진화_로드맵 연결)

```
현재 이 프로젝트:
  사람이 질문 → LLM 분석 → 사람이 대응

Deep RL 도입 시 (미래 시나리오):

상태(State):
  현재 보안 상태 (공격 건수, 위험도, 차단된 IP 등)

행동(Action):
  - IP 차단
  - 포트 차단
  - 관리자 알림
  - 로그 상세 수집

보상(Reward):
  - 공격 차단 성공: +1
  - 정상 트래픽 차단 (오탐): -0.5
  - 미탐지 (공격 통과): -2

학습:
  시뮬레이션 환경에서 수천 번 공격 시나리오 반복
  → 보상 최대화 전략 자동 학습
  → 실제 환경에 배포
```

## Multi-Agent RL — 진화_로드맵의 Multi-Agent와 연결

```
단일 에이전트 RL:
  하나의 에이전트가 모든 의사결정

Multi-Agent RL (MARL):
  여러 에이전트가 협력/경쟁하며 학습

보안 적용:
  [탐지 에이전트] 공격 패턴 탐지 전문
  [분석 에이전트] 위협 수준 판단 전문
  [대응 에이전트] 차단/알림 실행 전문
  → 각자 전문화, 협력으로 전체 성능 향상

현실:
  2026년 현재 연구 단계
  실제 보안 SOC 자동화에 적용 시작 단계
```

## 현재 한계

```
보안 RL의 어려움:

1. 보상 설계가 어렵다
   오탐과 미탐의 비용을 어떻게 수치화?
   비즈니스 영향을 어떻게 반영?

2. 시뮬레이션 환경 구축
   실제 공격 시나리오를 현실적으로 재현 필요
   실제 환경에서 학습하면 위험

3. 설명 가능성
   "왜 이 IP를 차단했나?" → RL은 설명 어려움
   규제, 감사 요구사항 충족 어려움

현실적 접근:
  완전 자동화보다 "의사결정 지원"으로 시작
  → LLM이 분석 + 대응 옵션 제안, 사람이 최종 결정
```
