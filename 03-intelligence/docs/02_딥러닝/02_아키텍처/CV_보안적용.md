# Computer Vision 보안 적용

> 작성일: 2026-03-20
> 이미지 기반 보안 분석 — CNN이 사이버보안에서 사용되는 방식

---

## 왜 보안에 이미지 분석이 필요한가

```
전통적 보안 분석: 텍스트/바이너리 → 시그니처 매칭
한계: 변종, 난독화, 패킹으로 시그니처 우회

이미지 기반 접근:
  바이너리/네트워크 데이터 → 시각화 → CNN 분류
  시그니처가 아닌 "시각적 패턴"으로 탐지
  난독화해도 전체적인 구조적 패턴은 유사
```

---

## 적용 1 — 악성코드 시각화 분석

### 원리

```
PE 파일(실행 파일) 바이트 → 2D 그레이스케일 이미지

방법:
  바이너리의 바이트 값(0~255)을 픽셀로 변환
  일정 너비로 줄바꿈 → 2D 이미지 완성

예시:
  1000바이트 파일 → 40×25 픽셀 이미지
  비슷한 악성코드 패밀리 → 비슷한 이미지 구조
```

### CNN 분류

```
학습:
  각 악성코드 패밀리의 시각적 이미지 수천 장 학습
  CNN이 패밀리별 시각적 특징 자동 추출

추론:
  새 악성코드 → 이미지 변환 → CNN → "Mirai", "WannaCry" 등 분류

장점:
  패킹/난독화 후에도 전체 구조 패턴은 남음
  변종 탐지에 강함 (원본과 시각적으로 유사)
  시그니처 업데이트 없이 패밀리 분류 가능

실제 연구:
  Nataraj et al. (2011) — 악성코드 시각화 분류 최초 제안
  VirusTotal에서 유사 기법 활용 중
```

---

## 적용 2 — 네트워크 트래픽 이미지 분류

```
원리:
  패킷 바이트 시퀀스 → 이미지 변환
  정상 트래픽, 공격 트래픽의 이미지 패턴이 다름

활용:
  암호화된 트래픽도 분류 가능 (내용이 아닌 구조로)
  VPN/TOR 트래픽 식별
  C2 (Command & Control) 통신 패턴 감지

한계:
  실시간 처리 시 패킷 → 이미지 변환 오버헤드
  충분한 학습 데이터 필요
```

---

## 적용 3 — 피싱 페이지 탐지

```
원리:
  웹페이지 스크린샷 → CNN → 피싱 여부 분류

방법:
  정상 은행/쇼핑몰 페이지 vs 피싱 페이지 스크린샷 학습
  CNN이 레이아웃, 색상, 로고 위치 패턴 학습

장점:
  HTML 소스 분석 없이 시각적 유사성으로 탐지
  제로데이 피싱 (새 도메인) 에도 적용 가능
  다국어 피싱 페이지 동일하게 처리
```

## 현대 트렌드 — ViT (Vision Transformer)

```
2021년 이후 CNN → ViT(Vision Transformer)로 점차 이동

이미지를 패치(조각)로 나눠 Transformer에 입력
→ 장거리 의존성 파악에 강함
→ 대규모 데이터셋에서 CNN 성능 능가

보안 적용:
  악성코드 이미지 분류에서 ViT가 CNN보다 높은 정확도
  멀티모달 모델(이미지+텍스트)로 보고서 자동 생성 가능
```
