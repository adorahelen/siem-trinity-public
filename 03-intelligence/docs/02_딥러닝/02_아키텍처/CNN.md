# CNN (Convolutional Neural Network)

> 작성일: 2026-03-20
> 딥러닝의 첫 번째 성공 사례 — 이미지 인식의 혁신

---

## 등장 배경

```
2012년 AlexNet 등장 전:
  이미지 인식 = 수작업 피처 엔지니어링 (전통 ML)
  사람이 "엣지", "색상", "질감" 등 피처를 직접 설계

2012년 AlexNet 이후:
  CNN이 이미지 피처를 자동으로 학습
  ImageNet 대회 오류율: 26% → 16% (압도적 우승)
  딥러닝 시대의 시작
```

---

## 핵심 아이디어 — 합성곱 (Convolution)

```
일반 신경망:
  이미지 전체 픽셀을 펼쳐서 입력
  1024x1024 이미지 → 100만 개 입력값
  → 파라미터 폭발

CNN:
  작은 필터(커널)로 이미지를 훑으며 특징 추출
  같은 필터를 전체 이미지에 반복 적용
  → 파라미터 대폭 절감 + 위치 불변 특징 학습
```

---

## 핵심 레이어 구성

### 합성곱 레이어 (Convolutional Layer)

```
필터(커널)가 이미지를 슬라이딩하며 특징 추출

작은 필터 (예: 3x3):
  처음 레이어: 엣지, 선 감지
  중간 레이어: 형태, 패턴 감지
  깊은 레이어: 눈, 코, 얼굴 등 고수준 특징

필터가 여러 개 → 여러 특징을 동시에 학습
```

### 풀링 레이어 (Pooling Layer)

```
특징 맵의 크기를 줄임 (다운샘플링)

Max Pooling:
  특정 영역에서 최대값만 남김
  → 약간의 위치 변화에 강인 (위치 불변성)
  → 파라미터 수 감소
```

### 완전 연결 레이어 (Fully Connected Layer)

```
최종 단계에서 추출된 특징을 받아 분류 수행
마지막에 Softmax → 클래스별 확률 출력
```

---

## 학습 흐름

```
입력 이미지
    │
[합성곱 + 활성화(ReLU)]  ← 특징 추출
    │
[풀링]                   ← 크기 축소
    │
[합성곱 + 활성화(ReLU)]  ← 더 추상적 특징
    │
[풀링]
    │
[완전 연결 레이어]        ← 분류
    │
[Softmax]               ← 확률 출력
```

## 주요 CNN 모델 역사

| 연도 | 모델 | 의의 |
|------|------|------|
| 2012 | AlexNet | 딥러닝 시대 개막, GPU 학습 최초 |
| 2014 | VGG | 깊이의 중요성 증명 (16~19층) |
| 2015 | ResNet | Skip Connection으로 100층+ 가능 |
| 2017 | DenseNet | 모든 레이어 연결 |
| 2021~ | ViT (Vision Transformer) | CNN 대신 Transformer로 이미지 처리 |

## CNN이 LLM에 미친 영향

```
CNN의 교훈:
  1. 깊은 네트워크가 복잡한 패턴 학습 가능 (증명)
  2. GPU 병렬 학습이 효과적 (증명)
  3. 계층적 특징 학습 (낮은 층 → 단순, 높은 층 → 복잡)

LLM이 계승한 것:
  깊은 네트워크 구조 (수백 레이어)
  GPU 기반 학습
  계층적 표현 학습 (텍스트 버전)

CNN이 해결 못한 것:
  순서가 있는 데이터 (텍스트) 처리
  → RNN → Transformer 로 진화
```

## 보안 도메인 CNN 적용

```
네트워크 트래픽 시각화 → CNN 분류:
  패킷 바이트를 2D 이미지로 변환
  → CNN으로 악성코드 패밀리 분류

악성코드 정적 분석:
  PE 파일 바이너리 → 그레이스케일 이미지
  → CNN으로 패밀리/변종 분류
  → 시그니처 없이 시각적 유사성으로 탐지

이 프로젝트 활용 가능성:
  로그 데이터 특성상 CNN보다 Transformer 계열 적합
```
