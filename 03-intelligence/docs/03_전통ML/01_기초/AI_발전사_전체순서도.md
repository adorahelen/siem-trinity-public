  1986  역전파(Backpropagation) 재발견
        BUT: 데이터 없음, CPU 너무 느림 → 이론만 존재

 전통 ML 전성기 (1990s~2000s)
  신경망 대신 수학적으로 증명 가능한 알고리즘이 현업 장악

  1995  SVM (Support Vector Machine)
  2001  랜덤포레스트 (Random Forest)
  2000s 부스팅 계열 (AdaBoost → Gradient Boosting)
  2014  XGBoost 등장 → Kaggle 대회 압도

  핵심 역량: 피처 엔지니어링
  "사람이 의미있는 숫자를 직접 뽑아 모델에 넣는다"

  한계: 텍스트/이미지/음성은 피처 설계가 매우 어려움

 딥러닝 르네상스 (2012~2017)

  2012  AlexNet — GPU로 ImageNet 우승 (오류율 26%→16%)
        "신경망 + GPU = 기존 ML 압도" 증명

  CNN (Convolutional Neural Network)
    이미지 인식, 의료영상, 자율주행
    피처 자동 학습 (엣지→모양→객체)

  2014  GAN (생성적 적대 신경망) — 이미지 생성 시작

  RNN / LSTM (Recurrent Neural Network)
    순서 있는 데이터 처리 (텍스트, 시계열)
    한계: 긴 문장에서 앞 내용 망각 (장기의존성 문제)
          순차 처리 → 병렬화 불가 → 느림

  2019  GPT-2 (OpenAI) — "너무 위험해서 공개 안 함" 선언

## 한 줄 요약

```
수학 → 이론 → 데이터+GPU → 딥러닝 → Transformer → LLM 대중화
     → 오픈소스 → 로컬 실행 → RAG/Agent → 지금
```

---

## 핵심 전환점 3가지

```
1. 2012 AlexNet
   "신경망은 이론이 아니다, 실용이다"
   → 전통 ML → 딥러닝 전환

2. 2017 Transformer
   "RNN 없이 Attention만으로"
   → 딥러닝 → LLM 전환

3. 2022 ChatGPT
   "AI는 연구자만의 것이 아니다"
   → LLM → 대중화 전환
```
