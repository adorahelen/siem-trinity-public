# AI / ML / DL / LLM 계층 관계

> 작성일: 2026-03-20
> 계기: "ML은 통계 기반, LLM은 별도 영역"이라는 오해에서 출발

---

## 계층 구조

```
AI (인공지능)
└── ML (머신러닝)
    └── 딥러닝 (Deep Learning)
        └── 신경망 기반 언어모델
            └── LLM (Large Language Model)
                └── 예: llama3.1:8b, qwen2.5:14b, Claude, GPT-4
```

LLM은 ML의 외부가 아닌, **ML 안에 포함되는 하위 개념**입니다.

---

## ML의 범위 오해

```
틀린 이해:
  ML = 통계 기반 (회귀, SVM, 랜덤포레스트만)
  LLM = ML과 별도

정확한 이해:
  전통적 ML = 통계/수식 기반 (회귀, SVM, 랜덤포레스트 등)
  현대 ML   = 신경망 포함 (CNN, RNN, Transformer 등)
  LLM       = Transformer 기반의 대형 신경망 → ML의 하위
```

## 각 레이어 설명

| 레이어 | 정의 | 예시 |
|--------|------|------|
| **AI** | 인간 지능을 흉내내는 모든 기술 | 체스 AI, 추천 시스템, LLM |
| **ML** | 데이터에서 패턴을 학습하는 알고리즘 | 랜덤포레스트, SVM, 신경망 |
| **딥러닝** | 여러 레이어의 신경망 사용 | CNN(이미지), RNN(시계열), Transformer(텍스트) |
| **LLM** | Transformer 기반 대규모 언어 모델 | llama3.1:8b, GPT-4, Claude |

---

## 전통적 ML vs 딥러닝 ML

```
전통적 ML:
  - 알고리즘: 랜덤포레스트, SVM, XGBoost, 로지스틱 회귀
  - 입력: 사람이 직접 선택한 피처 (IP, 포트, 패킷 수 등 숫자)
  - 신경망 사용: 없음
  - GPU 필요: 없음 (CPU로 충분)
  - 예: Suricata alert → 공격/오탐 분류기

딥러닝(신경망) ML:
  - 알고리즘: CNN, RNN, Transformer
  - 입력: 원시 데이터 (텍스트, 이미지, 음성)
  - 신경망 사용: 있음 (수백만~수백억 파라미터)
  - GPU 필요: 있음 (병렬 행렬 연산)
  - 예: LLM, 이미지 인식, 음성 인식
```

## 이 프로젝트 기준

```
사용 중:
  ✅ LLM (llama3.1:8b)         → 신경망 사용 (딥러닝)
  ✅ 임베딩 (nomic-embed-text) → 신경망 사용 (딥러닝)

미사용:
  ❌ 전통적 ML (랜덤포레스트 등)
  ❌ 직접 학습 (이미 학습된 모델을 추론에만 사용)
```

**핵심:** 이 프로젝트는 신경망을 사용하지만, 직접 학습시키지는 않는다.
이미 학습된 LLM/임베딩 모델을 가져다 **추론(inference)** 만 수행한다.
