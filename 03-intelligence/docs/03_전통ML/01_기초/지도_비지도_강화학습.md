# 지도학습 / 비지도학습 / 강화학습 — 학습 패러다임 3가지

> 작성일: 2026-03-20
> ML의 가장 근본적인 분류 기준 — "정답을 어떻게 제공하는가"

---

## 핵심 구분 기준

```
정답(레이블)이 있다       → 지도학습 (Supervised)
정답이 없다              → 비지도학습 (Unsupervised)
보상 신호로 스스로 학습   → 강화학습 (Reinforcement)
```

---

## 1. 지도학습 (Supervised Learning)

**정의:** 입력(X)과 정답(Y) 쌍을 주고 학습시키는 방식.

```
학습 데이터:
  X (입력)                Y (정답)
  ---                     ---
  [IP, 포트, 패킷수]   →  "공격"
  [IP, 포트, 패킷수]   →  "정상"
  [IP, 포트, 패킷수]   →  "공격"
  ...수천 건...

학습 결과:
  새 입력 [IP, 포트, 패킷수] → "공격" or "정상" 자동 예측
```

**두 가지 유형:**

| 유형 | 출력 형태 | 예시 |
|------|----------|------|
| 분류 (Classification) | 클래스 (공격/정상, 스팸/정상) | 악성코드 탐지, 이메일 스팸 필터 |
| 회귀 (Regression) | 연속 수치 (예상 가격, 예상 접속 수) | 서버 부하 예측, 주가 예측 |

**전제 조건:** 정답 레이블이 있어야 함 — 사람이 직접 하나씩 달아야 함.

---

## 2. 비지도학습 (Unsupervised Learning)

**정의:** 정답 없이 데이터 자체의 패턴/구조를 스스로 찾아내는 방식.

```
학습 데이터:
  X (입력만, 정답 없음)
  ---
  [IP, 포트, 패킷수]
  [IP, 포트, 패킷수]
  [IP, 포트, 패킷수]
  ...

학습 결과:
  "이 데이터들은 서로 비슷하다 (군집 A)"
  "이건 나머지와 완전히 다르다 (이상치)"
```

**두 가지 유형:**

| 유형 | 목적 | 예시 |
|------|------|------|
| 군집화 (Clustering) | 비슷한 것끼리 그룹 | 비슷한 접속 패턴 IP 그룹화 |
| 차원 축소 | 피처 수 줄이기 / 시각화 | 고차원 로그 데이터 2D로 표현 |

**장점:** 레이블 불필요 → 레이블링 비용 없음.
**한계:** "이 군집이 뭘 의미하는가"는 사람이 해석해야 함.

---

## 3. 강화학습 (Reinforcement Learning)

**정의:** 에이전트가 환경과 상호작용하며 보상을 최대화하는 방향으로 학습.

```
에이전트(Agent)
    │ 행동 선택
    ▼
환경(Environment)
    │ 보상(+) or 패널티(-) 피드백
    ▼
에이전트가 보상을 최대화하는 전략 학습
```

**특징:**
- 정답 레이블 없음 (지도학습과 다름)
- 시행착오 기반 (직접 해보고 결과 보고 수정)
- 순서가 있는 의사결정에 강함

**대표 사례:**
```
게임 AI:    알파고, OpenAI Five
로봇 제어:  Boston Dynamics 보행 학습
LLM 정렬:  RLHF (ChatGPT의 "사람처럼 대화" 학습에 사용)
```

---

## 3가지 비교

| | 지도학습 | 비지도학습 | 강화학습 |
|--|---------|----------|---------|
| 정답 | 필요 (레이블) | 불필요 | 불필요 (보상만) |
| 학습 방식 | 정답과 예측 오차 최소화 | 패턴/구조 발견 | 보상 최대화 |
| 대표 알고리즘 | 랜덤포레스트, SVM | K-Means, PCA | Q-Learning, PPO |
| 주요 어려움 | 레이블링 비용 | 결과 해석 | 보상 설계 |
| 보안 적용 | 악성코드 분류, 스팸 탐지 | 이상 트래픽 탐지 | 자동 대응 정책 |

---

## LLM과의 관계

```
Pre-training  → 지도학습 (다음 토큰 예측 — 정답: 실제 다음 토큰)
RLHF          → 강화학습 (사람 선호도 피드백 = 보상 신호)
임베딩 클러스터 → 비지도학습 (유사 의미 그룹화)

즉, 현대 LLM은 3가지 패러다임을 모두 조합해서 만들어집니다.
```
