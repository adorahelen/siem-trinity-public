# 과적합과 정규화 (Overfitting & Regularization)

> 작성일: 2026-03-20
> 전통 ML과 LLM 모두에 적용되는 핵심 개념

---

## 과적합 (Overfitting)이란?

훈련 데이터에 **너무 잘 맞춰진** 나머지, 새로운 데이터에는 성능이 떨어지는 현상.

```
비유:
  시험 족보만 달달 외운 학생
  → 족보 문제: 100점
  → 처음 보는 문제: 30점

ML 모델:
  훈련 데이터: 99% 정확도
  실제 새 데이터: 60% 정확도  ← 과적합
```

---

## 과적합 vs 과소적합

```
최적의 모델:
  훈련 데이터 정확도: 높음
  새 데이터 정확도:   높음  ✅

과적합 (Overfitting):
  훈련 데이터 정확도: 매우 높음 (거의 100%)
  새 데이터 정확도:   낮음  ❌
  원인: 모델이 너무 복잡, 훈련 데이터 노이즈까지 학습

과소적합 (Underfitting):
  훈련 데이터 정확도: 낮음
  새 데이터 정확도:   낮음  ❌
  원인: 모델이 너무 단순, 패턴을 못 잡음
```

---

## 과적합 발생 조건

```
1. 훈련 데이터가 너무 적다
   → 100개 데이터로 1000개 파라미터 학습 = 외워버림

2. 모델이 너무 복잡하다
   → 결정 트리가 너무 깊으면 훈련 데이터 모양 그대로 따라감

3. 훈련을 너무 오래 했다
   → 신경망에서 에포크(epoch)를 과하게 돌리면 발생
```

## 정규화 (Regularization) — 과적합 방지

모델이 훈련 데이터에 **지나치게 맞추지 못하도록 제약**을 거는 기법.

### L1 정규화 (Lasso)

```
핵심: 중요하지 않은 피처의 가중치를 0으로 만듦
효과: 피처 자동 선택 (불필요한 피처 제거)
적합: 피처가 많고, 일부만 실제로 중요할 때
```

### L2 정규화 (Ridge)

```
핵심: 모든 가중치를 0에 가깝게 줄임 (0으로 만들진 않음)
효과: 모든 피처를 작은 영향력으로 유지
적합: 피처 대부분이 의미 있을 때
```

### 드롭아웃 (Dropout) — 신경망 전용

```
훈련 중 무작위로 일부 뉴런을 꺼버림
→ 특정 뉴런에 의존하지 못하게 함
→ 여러 경로로 학습 → 일반화 능력 향상

LLM 훈련에도 사용됨
```

### 조기 종료 (Early Stopping)

```
훈련 중 검증 데이터 성능을 모니터링
→ 성능이 더 이상 좋아지지 않으면 훈련 중단
→ 과적합이 시작되기 전에 멈춤
```

---

## 과적합 탐지 방법

```
훈련/검증 데이터 분리 후 비교:

  훈련 정확도: 98%
  검증 정확도: 72%
  차이: 26%  → 심각한 과적합

정상 범위: 차이 5% 이내
```

---

## 교차 검증 (Cross Validation)

단순 훈련/검증 분리의 한계를 극복하는 방법.

```
K-Fold 교차 검증 (K=5):

  전체 데이터를 5등분
  ┌─────┬─────┬─────┬─────┬─────┐
  │  1  │  2  │  3  │  4  │  5  │
  └─────┴─────┴─────┴─────┴─────┘

  1라운드: [1,2,3,4] 훈련 / [5] 검증
  2라운드: [1,2,3,5] 훈련 / [4] 검증
  3라운드: [1,2,4,5] 훈련 / [3] 검증
  ...

  5번 평균 성능 → 더 신뢰할 수 있는 평가
```

## LLM에서의 과적합

LLM에도 과적합 개념이 적용됩니다.

```
파인튜닝 시:
  보안 로그 1,000건으로만 파인튜닝
  → 보안 로그 문체/패턴 과적합
  → 일반 대화 능력 상실 (Catastrophic Forgetting)

방지 방법:
  - 데이터 다양성 확보
  - LoRA (전체 파라미터 아닌 일부만 학습)
  - 원본 능력 유지 데이터 혼합 학습

이 프로젝트:
  파인튜닝 미사용 → 과적합 문제 없음
  RAG로 도메인 지식 주입 → 모델 원본 능력 그대로 유지
```
