# 전통 ML 보안 적용 사례

> 작성일: 2026-03-20
> 보안 도메인에서 전통 ML이 실제로 어떻게 사용되는가
> 이 프로젝트(LLM+RAG)와 어떻게 다른가

---

## 보안 도메인에서 전통 ML이 쓰이는 이유

```
보안의 특수성:
  - 실시간 처리 필요 (패킷 하나에 수 밀리초 이내 판단)
  - 대량 처리 (초당 수만 건 로그)
  - LLM은 수 초 소요 → 실시간 IDS에 부적합

전통 ML의 강점:
  - CPU만으로 밀리초 단위 예측 가능
  - 학습 완료 후 추론은 매우 가벼움
  - 판단 근거 추적 가능 (감사 로그 필요 시)
```

---

## 사례 1 — 네트워크 침입 탐지 (IDS)

```
목표: 네트워크 패킷이 공격인지 정상인지 실시간 분류

입력 피처:
  - 프로토콜 (TCP/UDP/ICMP)
  - 소스/목적지 포트
  - 패킷 크기
  - 연결 지속 시간
  - 플래그 (SYN, ACK, RST)

사용 알고리즘:
  - 랜덤 포레스트 (다양한 공격 유형 처리에 강함)
  - XGBoost (정밀도 우선 시)
  - SVM (고차원 피처에 효과적)

대표 데이터셋:
  NSL-KDD, CICIDS2017, UNSW-NB15

실제 제품:
  Snort (규칙 기반 + ML), Zeek (스크립팅 + ML 연동)
```

---

## 사례 2 — 악성코드 탐지

```
목표: 실행 파일이 악성코드인지 분류

정적 분석 피처 (실행 안 하고 분석):
  - PE 헤더 구조 (섹션 수, 엔트리포인트 등)
  - Import 함수 목록 (CreateProcess, WriteFile 등)
  - 파일 엔트로피 (암호화/난독화 여부)
  - 문자열 패턴

동적 분석 피처 (실제 실행하며 관찰):
  - API 호출 시퀀스
  - 레지스트리 접근 패턴
  - 네트워크 연결 시도

사용 알고리즘:
  - 랜덤 포레스트 (피처 중요도로 어떤 특징이 결정적인지 파악)
  - 그래디언트 부스팅 (정밀도 향상)

실제 제품:
  Windows Defender, CrowdStrike Falcon (ML 엔진 내장)
```

## 사례 3 — 이상 탐지 (Anomaly Detection)

```
목표: 정상 패턴을 학습하고, 벗어나는 것을 탐지

특징: 정상 데이터만으로 학습 (비지도학습)
     → 레이블 없이도 가능

적용 사례:
  - 사용자 행동 분석 (UEBA): 평소와 다른 로그인 시간/위치
  - 내부자 위협: 평소보다 훨씬 많은 파일 접근
  - 서버 이상: 평균 CPU/네트워크 패턴 이탈

사용 알고리즘:
  - Isolation Forest (이상치를 빠르게 고립)
  - One-Class SVM (정상 클래스 경계 학습)
  - Autoencoder (재구성 오차가 큰 것 = 이상)

이 프로젝트 Wazuh와 비교:
  Wazuh: 규칙 기반 (level 7 이상이면 경보)
  ML 이상탐지: 통계적 기준선에서 벗어나면 경보
  → 조합 시 탐지율 향상
```

---

## 사례 4 — 스팸 / 피싱 탐지

```
목표: 이메일이 스팸/피싱인지 분류

피처:
  - 발신 도메인 평판
  - URL 수, 첨부 파일 유형
  - 헤더 이상 여부
  - 텍스트 키워드 빈도 (TF-IDF)

사용 알고리즘:
  - 나이브 베이즈 (텍스트 분류 전통 강자, 매우 빠름)
  - 로지스틱 회귀 (해석 가능)

특이점:
  이 분야는 LLM으로 대체되는 중
  → GPT 계열로 피싱 문구 분석이 훨씬 정교해짐
```

## 전통 ML vs LLM+RAG — 보안 도메인 비교

| 항목 | 전통 ML (보안) | LLM + RAG (이 프로젝트) |
|------|--------------|----------------------|
| 처리 속도 | 밀리초 | 수 초 |
| 처리량 | 초당 수만 건 | 수 건 |
| 레이블 필요 | 필요 | 불필요 |
| 새 공격 패턴 | 재훈련 필요 | 로그 동기화만 |
| 설명 생성 | 불가 | 자연어 설명 가능 |
| 적합한 역할 | 실시간 1차 필터링 | 사후 상세 분석 |
| 적합한 질문 | "이게 공격인가?" | "어제 공격 패턴을 분석해줘" |

## 현실적 조합 아키텍처

대형 보안 솔루션은 두 방식을 계층적으로 조합합니다.

```
네트워크 트래픽/로그
      │
      ▼
[Layer 1 — 전통 ML]
  랜덤 포레스트 / XGBoost
  밀리초 단위 실시간 분류
  → 정상: 통과
  → 의심: 다음 레이어로
      │
      ▼
[Layer 2 — 규칙 기반]
  Suricata / Wazuh 시그니처 매칭
  → 알려진 패턴이면 즉시 경보
      │
      ▼
[Layer 3 — LLM + RAG]  ← 이 프로젝트 위치
  사람이 질의하거나
  복잡한 패턴 분석 요청 시
  심층 맥락 분석 + 보고서 생성
```

이 프로젝트는 Layer 3 역할 — 실시간 탐지가 아닌 **사후 분석 및 보고**에 최적화되어 있습니다.
